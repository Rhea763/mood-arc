心绪日历 · 产品说明文档

定位：帮助理解、表达、陪伴自己情绪的音乐日记（不是单纯 Mood → Playlist）。

1. 三大入口（顶栏）

入口URL职责
心情歌单#playlist即时陪伴：签到 → 匿名日记 → 情绪歌单+引导
心情日历#calendar待办 + 长期情绪历程沉淀
晚间心书#journal听完后再次记录，形成 before/after 闭环

旧链接兼容：#mood → 心情歌单，#evening → 晚间心书。

给 ChatGPT / AI 的提示：主应用 /xinshu#mood 是单页应用，需 JavaScript 才能看到交互界面。若要理解产品逻辑，请阅读本页 /xinshu/guide.html 或 /xinshu/guide.txt。

2. 心情歌单三步流（#playlist）

  1. 心情签到 — 选 mood 标签、强度 1–10、需求（安慰/消化/转移/能量/保持快乐）+ 开心/烦恼
  2. 匿名日记 — 根据烦恼生成匿名故事与提示（原「今日梳理」日记本逻辑）
  3. 情绪歌单 — MoodArc iframe：音乐 + 每首歌的情绪陪伴解释（非单纯曲风标签）

iframe 参数新增：intensity、intention（comfort/process/distraction/energy/celebrate）。

3. 晚间心书（#journal）

听完后问「你现在的心情是？」记录 after mood + 强度 + 反思。展示 Today's Mood Journey（before → after），文案不说「音乐治愈你」，只说感受变化。

3.1 开心的事（2 条输入框）

  • 字段 id：mpHappy1、mpHappy2
  • placeholder：「写下一件让你开心的事…」「还有吗？再写一件…」
  • 每条最多 60 字
  • 存储：state.mood.happy[0]、state.mood.happy[1]

3.2 不开心的事（2 条输入框 + 快捷建议）

  • 字段 id：mpSad1、mpSad2
  • 可点击快捷标签一键填入，或手动输入
  • 存储：state.mood.sad[0]、state.mood.sad[1]

快捷建议文案（15 条）：

  • 学习压力有点大、和朋友闹了点不愉快、家里的事让我烦恼
  • 最近情绪起伏很大、对自己有点不确定、对未来有点迷茫
  • 有些话不知道怎么说、今天太累了、感觉没人理解我
  • 被人批评了、担心考试/成绩、和同学相处不愉快
  • 觉得自己不够好、有件事一直放不下、说不清楚为什么不开心

3.3 今天的心情标签（单选式多标签，可多个 active）

可选标签（8 个）：

  • 😊 开心
  • 😌 平静
  • 😰 焦虑
  • 😫 疲惫
  • 😠 愤怒
  • 😢 低落
  • 🙏 感恩
  • 😶 迷茫

存储：state.mood.tags（字符串数组）

3.4 页面导航

  • 上一步：← 心绪日历（#calendar）
  • 下一步：晚间梳理 →（#evening）

4. MoodArc 歌单集成（#playlist）

心绪日历在「心情歌单」页嵌入 iframe，地址为 https://mood-arc.vercel.app/embed。当用户进入 #playlist 时，会把 #mood 页填写的内容同步为 URL 参数：

https://mood-arc.vercel.app/embed?embed=1
  &mood=焦虑          （来自心情标签映射，见下表）
  &causes=学业,感情    （从开心/烦恼文本关键词推断）
  &happy=今天阳光很好|吃了喜欢的饭
  &sad=学习压力有点大|和朋友闹了不愉快
  &tags=😰 焦虑|😫 疲惫

4.1 心情标签 → MoodArc mood 映射

心绪日历标签MoodArc mood 参数
😊 开心开心
😌 平静平静
😰 焦虑焦虑
😫 疲惫疲惫
😠 愤怒愤怒
😢 低落失落
🙏 感恩满足
😶 迷茫孤独

映射规则：按 tags 数组顺序，取第一个能映射的标签作为 mood。

4.2 原因（causes）关键词推断

从 happy + sad 合并文本中匹配：

  • 感情：感情、恋爱、分手、对象、喜欢、前任
  • 工作：工作、上班、加班、老板、同事、项目
  • 学业：学业、考试、作业、论文、学习、学校
  • 人际：朋友、人际、社交、关系、沟通
  • 家庭：家庭、父母、家人、家里
  • 健康：身体、健康、生病、睡眠、累
  • 经济：钱、经济、消费、账单
  • 若无匹配：说不清

5. MoodArc 能力摘要（嵌入页 / 主站）

  • 情绪选择：伤心、焦虑、开心、愤怒、疲惫、平静等
  • 强度滑块：1–10 级情绪强度
  • 调节意图：如安慰、释放、分心、能量、反思等
  • 歌单生成：基于情绪弧线打分 + 歌曲情绪标签库（63+ 首 rich profile）
  • 推荐说明：每首歌显示情绪匹配度与推荐理由
  • 播放来源：优先 YouTube；不可用时显示「网易云」「QQ 音乐」跳转
  • 心情历程：/journey 页本地记录历史（localStorage）

6. 晚间梳理（#evening）情绪策略

用户对每条「烦恼」可选择应对方式：

  • 💭 看见它（acknowledge）
  • 🗣️ 找人聊聊（talk）
  • 🔄 换个角度（reframe）
  • 🕊️ 放下它（release）
  • ❤️ 抱抱自己（selfcare）

系统会根据烦恼文本主题（学业、疲惫、人际、自我怀疑、焦虑、孤独、失去、失败、健康、家庭等）生成匿名日记风格的开场与安慰语。

7. 心绪日历（#calendar）

  • 添加今日事项（文字 + 可选时间）
  • 统计：已完成 / 未完成 / 今日事项总数
  • 数据存 localStorage，支持重置

8. 技术栈

  • 心绪日历：纯 HTML + CSS + JavaScript 单文件（public/xinshu/index.html）
  • MoodArc：Next.js 16，部署于 Vercel
